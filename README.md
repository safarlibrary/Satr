# سطر — متجر قرطاسية وأدوات مدرسية

نسخة قابلة للتعديل من موقع «سطر»: نفس التصميم بالضبط، مع سيرفر حقيقي ولوحة تحكم فيها التكاملات.

- **الواجهة:** React 19 + Vite + Tailwind 4 (`src/`)
- **السيرفر:** Node.js + Express (`server/`)
- **قاعدة البيانات:** SQLite المدمجة في Node — ملف واحد `satr.db` داخل `DATA_DIR`
- **يحتاج:** Node 22.13 أو أحدث

## التشغيل

```bash
cd satr
npm install
npm run dev          # http://localhost:3000
```

لوحة التحكم: `http://localhost:3000/#/admin` والتوكن في وضع التطوير `dev-admin-token`.

## الرفع على السيرفر

```bash
cp .env.example .env   # وعبّي ADMIN_TOKEN و SETTINGS_SECRET
npm install
npm run build
npm start
```

حط السيرفر خلف Caddy أو Nginx مع HTTPS. انسخ مجلد `data/` احتياطيًا، ففيه كل الطلبات والمنتجات والمفاتيح.

`npm run build:preview` يطلع نسخة بدون سيرفر في `dist-preview/`، وبياناتها تنحفظ في المتصفح فقط (للعرض).

## حساب العميل

- **تسجيل الدخول برقم الجوال:** رمز من ٤ أرقام يوصل SMS (يحتاج تفعيل «رسائل SMS» من التكاملات). في وضع التطوير بدون SMS يظهر الرمز في الصفحة.
- **حسابي:** طلباته وحالتها ورابط التتبع، وتقييم المنتجات بعد ما توصله.
- **إتمام الطلب:** قائمة المدن، خريطة يحدد عليها موقعه وتتعبى الحي والشارع تلقائيًا (OpenStreetMap)، وخانة ملاحظة.
- **صور المنتج:** تتقلّب بالسحب في بطاقة المنتج وصفحته (صورة لكل لون + صور إضافية من لوحة التحكم).

## لوحة التحكم

- **الإحصائيات والمخزون:** المبيعات والربح التقديري بالفترة، الأكثر مبيعًا، ولكل منتج ولون: الكمية الكلية، كم انباع، وكم باقي.
- **العملاء والرسائل:** كل عميل وتحته طلباته، وترسل له بالبريد من قوالب موحّدة (فاتورة، تم الشحن، تأكيد، عقد) وتطبع الفاتورة.
- **السلات المتروكة:** اللي حطوا منتجات وما كمّلوا من ساعة وأكثر، مع تذكير بالواتساب أو SMS.
- **نبّهني إذا توفّر:** مين ينتظر أي منتج أو لون، ورسالة SMS تلقائية لما ترجّع الكمية.
- **التقييمات:** نجوم وتعليق من العملاء اللي وصلهم طلبهم، وتقدر تخفيها أو تحذفها.
- **الطلبات:** أرقام اليوم، ملاحظة العميل وموقعه على الخريطة، وكم باقي من كل منتج ولون، المنتجات اللي قرّبت تخلص، تغيير الحالة، شركة الشحن ورقم الشحنة، زر واتساب للعميل، تأكيد التحصيل.
- **المنتجات:** إضافة وتعديل وإخفاء ورفع صور.
- **قوائم المدارس:** القوائم المرفوعة مع ملفاتها.
- **الإعدادات:** الهوية والدومين (البريد الرسمي، اسم المرسل، وثيقة العمل الحر، مركز الأعمال، واتساب بزنس)، حسابات التواصل، رسوم التوصيل والمخزون. اللي تعبّيه يظهر في الفوتر، وواتساب يظهر كزر عائم.
- **الأجهزة:** تدخل بالتوكن مرة وحدة على كل جهاز، وبعدها اللوحة تفتح منه مباشرة. تقدر تلغي أي جهاز من الإعدادات.
- **التكاملات:** (المفاتيح تنحفظ مشفّرة وما ترجع للمتصفح، ولكل تكامل زر «احفظ واختبر»)

| التكامل | وش يسوي |
|---|---|
| ميسّر | دفع مدى وApple Pay وSTC Pay والبطاقات، بوضعين Test وLive لكل واحد مفاتيحه وWebhook Secret. السيرفر يتأكد من الدفع مع ميسّر مباشرة |
| Apple Pay و DNS | محتوى ملف التحقق يُعرض على `/.well-known/apple-developer-merchantid-domain-association`، وسجلات DNS للمرجع |
| البريد — SMTP | تنبيهات من بريدك نفسه (Gmail وغيره)، ولو مشغّل يُستخدم بدل Resend |
| تابي | التقسيط على ٤ دفعات، يظهر كخيار إضافي في صفحة الدفع |
| واتساب للأعمال | رسائل للعميل: تأكيد الطلب، الشحن مع رابط التتبع، التوصيل (قوالب Meta معتمدة) |
| SMS (تقنيات) | نفس الرسائل كرسائل نصية |
| تيليجرام | تنبيه فوري لك مع كل طلب أو دفع أو قائمة مدرسة |
| البريد (Resend) | نفس التنبيهات على بريدك |
| شركات الشحن | روابط التتبع لكل شركة، تظهر للعميل في صفحة تتبع الطلب |
| التحليلات والبكسلات | GA4، Tag Manager، Google Ads، Meta، تيك توك، سناب: مشاهدة، إضافة للسلة، بدء الدفع، شراء |
| ملف المنتجات | `/feed/products.xml` لـ Google Merchant وكتالوج Meta وتيك توك وسناب |
| Webhook | يرسل الأحداث لـ Zapier أو Make أو n8n مع توقيع HMAC |

سجل الإرسال تحت صفحة التكاملات يعرض كل رسالة انرسلت ونتيجتها.

> قبل التشغيل الحقيقي جرّب كل تكامل بمفاتيح الوضع التجريبي: تابي وتقنيات وروابط تتبع شركات الشحن ما انجرّبت على حسابات حقيقية.

## أدوات الطالب المجانية (`/tools`)
- الصفحات: `/tools` (الرئيسية)، `/tools/cover` (صانع غلاف الواجبات)، `/tools/pdf` وتحتها `images` و`merge` و`split` و`compress`.
- كلها تشتغل داخل متصفح الطالب: الملفات ما تنرفع للسيرفر ولا تنحفظ.
- البيانات الوصفية (العنوان والوصف) في `shared/tools.js`، والسيرفر يحقنها في الصفحة للسيو، ويوفّر `/sitemap.xml` و`/robots.txt`.
- المكتبات تتحمّل فقط داخل صفحات الأدوات (pdf-lib وpdfjs-dist وheic2any وhtml-to-image).
- **السيرة الذاتية** `/tools/cv` و**تنسيق التقارير** `/tools/report`: تعبئة وقوالب ومعاينة A4 وتحميل PDF/PNG داخل المتصفح. فيهم زر اقتراحات بالذكاء الاصطناعي اختياري.
- **الذكاء الاصطناعي:** من لوحة التحكم ← التكاملات ← «الذكاء الاصطناعي»: ضع مفتاح جمناي أو OpenAI، وفعّل «إعدادات أدوات الذكاء الاصطناعي». المفتاح يبقى في السيرفر (`server/routes/ai.js`)، وفيه حد يومي لكل جهاز وحد كلي وأقصى طول للنص. بدون مفتاح تشتغل الأدوات عادي وبدون زر الاقتراحات.
- الضغط: خفيف (بدون خسارة)، متوسط (يضغط صور JPEG داخل الملف)، قوي (يحوّل الصفحات لصور).

> نشر الواجهة فقط على Vercel: الأدوات تشتغل كاملة لأنها داخل المتصفح، أما المتجر (الطلبات والحسابات ولوحة التحكم) فيحتاج سيرفر Node. الإعداد في `vercel.json`.
